# MorphDrop v1.3.0 - The Pro Workstation Update

## 🚀 Enhancements
- **On-Device OCR:** Extract text from any image or scanned PDF completely offline (Supports English, Chinese, Hindi, Japanese, Korean).
- **Pro PDF Viewer:** A Google Drive-style PDF engine with text search, page jumping, bookmarks, immersive mode, and night/sepia reading modes.
- **Privacy Metadata Editor:** Inspect, strip, or selectively edit hidden GPS and EXIF tracking data from your files before sharing.
- **Interactive Image Workbench:** A new visual grid interface for images with in-place cropping, rotating, and robust batch processing support.
- **In-App GitHub Updater:** MorphDrop will now silently check for updates in the background and notify you when a new version is available on GitHub.
- **Material You Polish:** Enjoy zero-flash navigation transitions and dynamic wallpaper theming for Android 12+ devices.
