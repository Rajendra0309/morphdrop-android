# MorphDrop v1.2.0 - The Ultimate PDF Overhaul

## 🚀 Enhancements
- **Interactive PDF Workbench:** A high-end visual grid interface for merging, splitting, and organizing PDFs. Say goodbye to legacy text-based inputs!
- **Advanced Merge:** Seamlessly interleave pages from multiple documents with our new Master Visual Workbench and dynamic color badges.
- **Enhanced Compression:** Our new strict byte-size guardian prevents file size inflation, and we've fixed alpha transparency issues for perfect visual accuracy.
- **Iron-Clad Security:** Major improvements to PDF password protection, ensuring absolute enforcement of printing, copying, and editing restrictions.
- **Workstation UI:** A complete overhaul of the PDF tools to match our premium, dynamic Material 3 design language.
