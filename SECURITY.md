# Security Policy

## Supported Versions

Currently, only the latest version of MorphDrop is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within MorphDrop, please send an e-mail to morphdrop88@gmail.com. All security vulnerabilities will be promptly addressed.

Please do **not** report security vulnerabilities through public GitHub issues.

When reporting a vulnerability, please include:
- A description of the vulnerability and its impact.
- Steps to reproduce the issue.
- Any potential solutions or workarounds if known.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If you report a vulnerability that affects our users, we will give you credit for discovering it (if desired) once the vulnerability has been resolved and the fix has been deployed.
